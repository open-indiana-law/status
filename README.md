# Open Indiana Law status

[![check](https://github.com/open-indiana-law/status/actions/workflows/check.yml/badge.svg)](https://github.com/open-indiana-law/status/actions/workflows/check.yml)

Public, independent check of the hosted Indiana Code MCP at <https://mcp.openindianalaw.org>.
Every five minutes GitHub runs three tests from outside our own network: the health page, a real statute
lookup (IC 35-42-1-1) and a real full-text search. Green badge: all three passed on the last run. Red: they
failed three times in a row. See the [run history](https://github.com/open-indiana-law/status/actions/workflows/check.yml).

Unofficial service. Not legal advice. Verify every citation at the official source. GitHub scheduled runs can be
delayed, so a gap is not proof of an outage.
